## 📋 Project Summary

**UniCarona** is a digital web platform tailored for peer-to-peer carpooling within the **UNISINOS** community. Conceived within the **Law Degree curriculum**, the software integrates shared economy principles, sustainable mobility, and data protection (LGPD framework) to address campus commuting challenges.
