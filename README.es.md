## 📋 Descripción del Proyecto

**UniCarona** es una solución digital de economía compartida orientada a conectar estudiantes de la comunidad **UNISINOS** para coordinar viajes compartidos hacia el campus. El proyecto une el análisis jurídico del derecho al transporte y la normativa de protección de datos (LGPD) con la ingeniería de software aplicada.
